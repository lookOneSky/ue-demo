# DemoDasPolylineLayer 多段线图层组件

## 概述

这是一个基于DasPolylineTool和DasPolylineLayer接口实现的多段线图层演示组件，集成到了TabMenu系统中。

## 功能特性

### 工具控制
- **启动/停止工具**: 激活多段线绘制工具
- **创建多段线图层**: 基于工具绘制的点位创建图层
- **调试工具数据**: 输出当前工具状态和数据

### 图层操作
- **定位图层**: 飞行到图层位置
- **显隐图层**: 切换图层可见性
- **删除图层**: 移除所有图层

### 多段线属性控制
- **线条颜色**: RGBA颜色控制 (0-1范围)
- **线条粗细**: 可调节线条粗细
- **屏幕空间固定**: 控制线条粗细是否固定屏幕空间
- **深度测试**: 启用/禁用深度测试
- **深度偏移**: 调节深度偏移量
- **光晕效果**: 控制光晕的启用、宽度和强度
- **样条插值**: 控制样条插值和插值点数量

### 批量操作
- **批量更新所有属性**: 一次性更新所有线条属性

## 使用方法

1. 在TabMenu中选择"多段线图层"选项卡
2. 点击"启动工具"激活多段线绘制工具
3. 在3D场景中点击添加多段线节点
4. 调整线条属性参数
5. 点击"创建多段线图层"生成图层
6. 使用属性控制面板实时调整线条外观

## 技术实现

### 依赖接口
- `DasPolylineTool`: 多段线绘制工具
- `DasPolylineLayer`: 多段线图层管理
- `DasGroupLayer`: 图层组管理

### 核心方法
- `startTool()`: 启动绘制工具
- `createPolylineLayer()`: 创建图层实例
- `updateLineColor()`: 实时更新线条颜色
- `updateAllProperties()`: 批量更新属性

### 数据流
1. 工具绘制 → 获取点位数据
2. 创建图层 → 应用初始属性
3. 实时调整 → 更新图层属性

## 集成到TabMenu

组件已集成到`src/components/TabDemo.vue`中：
- 导入: `import DemoDasPolylineLayer from './DemoDasPolylineLayer.vue'`
- 选项卡: `{ id: 'polylineLayer', name: '多段线图层', icon: 'tool-icon' }`
- 模板: `<DemoDasPolylineLayer />` 当选中对应选项卡时显示

## 错误处理

组件包含完善的错误处理机制：
- Try-catch包装所有异步操作
- 控制台输出详细错误信息
- 状态面板显示当前工具状态

组件设计具有良好的扩展性：
- 模块化的属性控制方法
- 灵活的数据格式兼容
- 可配置的参数范围
- 支持批量操作
