# 多段线示例

工作台的「多段线绘制」和「多段线图层」分别演示现场采点与已保存图层的操作。两个页面都有按钮切换到另一个页面。

## 绘制并保存

1. 连接 UE 后进入「多段线绘制」，点击「启动绘制」，在视口中依次点击添加节点。
2. 在「绘制线样式」调整颜色、线宽、深度测试、可见性或样条插值。点击「读取工具数据」可查看工具当前返回的点位和属性。
3. 点击「保存为图层」，等待页面显示新图层 ID。点击「管理多段线图层」，即可接着调整刚保存的折线。离开绘制页面会结束当前绘制。

## 管理已保存的图层

进入「多段线图层」时，工作台会读取场景根节点下的折线，并优先选中上次选择或刚保存的图层。如有多个折线图层，可从「目标图层」选择 ID，再定位、显示、隐藏或删除。其他示例添加或移除图层后，可点击「刷新图层」。

「图层样式」可逐项调整颜色、线宽、深度测试、深度偏移、光晕、亮度与样条插值。「批量应用图层样式」会把当前表单参数一起应用到所选图层。

每条折线在本次工作台会话中有独立的样式草稿。绘制页保存的折线会带入工具返回的颜色、线宽、深度测试和插值设置。场景中已有的折线从默认草稿开始，切换图层或重新进入示例会恢复各自的草稿。
