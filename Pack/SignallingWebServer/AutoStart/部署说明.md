# 信令服务器自启动部署

1. 把整个 `SignallingWebServer` 文件夹拷到目标机器。
2. 打开 `dist/config.json`，把 `UEProgram` 改成本机 UE 程序的路径。
3. 用推流用的 Windows 账户登录，双击 `AutoStart/install-user-autostart.bat`。
4. 窗口显示 `Installed and started` 即完成，以后该账户登录就会在后台自动启动。

安装报错 `Legacy service ... is installed` 时，用管理员 PowerShell 执行下面两行，再重做第 3 步：

    sc.exe stop PixelStreamingSignallingServer
    sc.exe delete PixelStreamingSignallingServer
